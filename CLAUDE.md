# FitFat — правила проекта

- Android, Kotlin, Jetpack Compose, Material 3. Тексты интерфейса на русском.
- Перед тем как сказать «готово», собери проект: `gradlew assembleDebug` должен пройти без ошибок.
- Не обновляй версии AGP, Kotlin и Gradle без отдельной просьбы. Если обновляешь — поменяй и `gradle-version` в `.github/workflows/*.yml`.
- База данных Room: при изменении сущностей повышай версию и пиши миграцию. Данные пользователя терять нельзя, `fallbackToDestructiveMigration` не использовать.
- Ключ подписи и пароли не трогать и не создавать.
- Каждое заметное изменение записывай в `CHANGELOG.md` в раздел следующей версии (`## [x.y.z]`).
- Цвета только из темы (`MaterialTheme.colorScheme`) и `MacroColors`, без случайных HEX.
- Дизайн-референс — макеты в проекте Claude «Приложение для подсчёта БЖУ».
