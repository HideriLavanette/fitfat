# Fitfat — Android-приложение для подсчёта КБЖУ

Kotlin + Jetpack Compose, Material 3. Обновления приходят из GitHub Releases, Google Play не нужен.

## Как устроены обновления

1. Вы ставите тег `v0.2.0` и пушите его.
2. GitHub Actions собирает APK, подписывает его вашим ключом и публикует релиз `fitfat-0.2.0-<код>.apk`. Описание берётся из `CHANGELOG.md`.
3. Приложение раз в 12 часов (и по кнопке в профиле) смотрит релизы, сравнивает `versionCode` и предлагает обновиться. Скачивает APK и открывает системный установщик. Данные сохраняются.

Теги с дефисом (`v0.3.0-beta1`) публикуются как бета. Их видят только те, у кого в профиле включены бета-версии.

## Настройка один раз

### 1. Репозиторий
Создайте репозиторий на GitHub и пропишите его в `gradle.properties`:
```
updateRepo=ваш-логин/fitfat
```
Репозиторий должен быть **публичным**: приложение читает релизы без токена. Если исходники хочется держать закрытыми, заведите отдельный публичный репозиторий только для релизов (это потребует токена в workflow, напишите, если нужно).

### 2. Ключ подписи
Ключ создаётся один раз и **никогда не меняется**: обновление с другой подписью Android не установит поверх старой версии.

```
keytool -genkeypair -v -keystore release.jks -alias fitfat -keyalg RSA -keysize 4096 -validity 10000
```
Сохраните `release.jks` и пароли в надёжном месте (менеджер паролей). В git его не добавляйте, он уже в `.gitignore`.

Переведите ключ в base64:
- Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.jks")) | Set-Clipboard`
- Linux/macOS: `base64 -w0 release.jks`

### 3. Секреты GitHub
Settings → Secrets and variables → Actions → New repository secret:

| Имя | Значение |
|---|---|
| `KEYSTORE_BASE64` | строка base64 из шага 2 |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `fitfat` |
| `KEY_PASSWORD` | пароль ключа |

### 4. Первый релиз
```
git tag v0.1.0
git push origin v0.1.0
```
Через несколько минут во вкладке Releases появится APK. Скачайте его на телефон и установите вручную, разрешив установку из этого источника. Дальше приложение обновляется само.

## Выпуск новой версии
1. Добавьте раздел `## [0.2.0]` в `CHANGELOG.md`.
2. `git tag v0.2.0 && git push origin v0.2.0`.

## Локальная разработка
Откройте папку в Android Studio (Ladybug или новее) и дождитесь синхронизации Gradle. Отладочная сборка ставится отдельным приложением (`app.fitfat.debug`) и не мешает рабочей.
