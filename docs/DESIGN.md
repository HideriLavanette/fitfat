# FitFat — решения по продукту и дизайну

Источник: обсуждение и интерактивные макеты в проекте Claude «Приложение для подсчёта БЖУ»
(холст макетов: https://claude.ai/artifact/LwcEEHcKWTUrGCBS96TfRY — доступен автору).
Если что-то здесь противоречит коду — прав этот документ, код надо привести к нему.

## Общие принципы
- Ввод еды и веса — максимум за 10 секунд. Всё работает офлайн, данные на телефоне.
- Всё, что крутится (вес, граммы, БЖУ), — барабаны/колёса с инерцией, доводкой до значения, **звуком щелчка и вибрацией на каждом шаге**. Начертание чисел (размер, жирность, цвет) меняется плавно по мере приближения к центру, без скачков.
- Удаление везде: свайп влево → элемент исчезает → снизу snackbar «„Название“ удалён» с небольшой кнопкой «Отмена» справа, висит 5 секунд.
- Удаление продукта/блюда целиком — кнопка-корзина в правом верхнем углу экрана редактирования + диалог подтверждения.
- Кнопки без действия не оставлять (никаких «⋮» без меню). У каждого топбара — заголовок.

## Тема
- Тёмная по умолчанию, Material 3 tonal spot от seed `#E8749F` (схемы уже в `Theme.kt`). Primary `#FFB0C9`.
- Макросы (свои цвета): белки `#D3C4F5` / контейнер `#332B45`; жиры `#E6D09A` / `#3A3122`; углеводы `#EEBD9E` / `#3D2A21`.
- Перебор — `#FF5C63`. Тренировка — голубой `#8AB4FF`. Цикл — `#FF8A8A`.
- В подписях БЖУ — буквы Б/Ж/У жирным в цвете макроса, в одну строку.
- Размытие (blur) — **только** у навбара и зоны под ним. Скримы модалок и шторок без блюра.

## Навигация
- Плавающий навбар-капсула (72 dp, отступы 16 dp), 4 пункта с подписями: Сегодня · Вес · Ассистент · Профиль. Индикатор 56×32 secondaryContainer.
- Под навбаром защитная зона ~120 px: контент под ней размывается и не принимает тапы.

## Вес
- **Утреннее окно** — модалка поверх главного экрана, раз в день, пока вес не введён. Колесо: тонкое кольцо, 6 крупных меток на оборот (каждые 0,5 кг), между ними точки; 12° = 0,1 кг; хват в любом месте круга; инерция; пружинная доводка. Под числом «вчера X · ±Y». Ниже — блок «За неделю»: изменение и спарклайн с днями Сб–Пт.
- **Подсказка-обучение**: при первом запуске поверх кольца анимированный палец ведёт дугу, число меняется; повторяется, пока пользователь сам не покрутит. Текстовой подсказки «крутите» нет.
- **История**: график (точки + сглаженный тренд EMA α=0,1 + пунктир прогноза), периоды 1 нед / 1 мес / 3 / 6 / 1 год; смена периода ещё и удержанием + свайпом по графику. Список — календарём на 5 недель: в ячейке вес, пропуск — «—», тренировка — голубая полоска, цикл — красная заливка, сегодня обведено.
- **Правка записи** — шторка: вес ±, отметки «Тренировка» / «Цикл», заметка; кнопки «Отмена» и «Сохранить».
- **Скачок веса**: если утром вес заметно выше тренда после дня с перебором соли/углеводов — карточка «+0,9 кг за ночь — это вода», тренд не изменился, объяснение, кнопки «Смотреть тренд» / «Понятно».

## Главный экран
- Сверху капсула даты: свайп влево — вчера, вправо — вперёд (не дальше сегодня), тап — календарь месяца.
- Тип дня: Обычный / Тренировка (голубой) / Цикл (красный), запоминается на дату.
- Волнистое кольцо остатка калорий + волнистые полоски Б/Ж/У с точкой-ограничителем. Перебор — поверх полного прогресса красная волна толще на пару px, её длина растёт с размером перебора.
- Нормы по умолчанию: Б 180 · Ж 60 · У 140 (1 820 ккал); в день тренировки У 240.
- Дневник: от последнего приёма к первому. Два режима группировки: Завтрак/Обед/Ужин или по времени.
- Строка записи: свайп вправо — повтор (модалка порции, запись на текущее время), свайп влево — удаление с отменой, тап — шторка правки (граммы, КБЖУ, кнопки Удалить / Повторить / Карточка продукта).

## Добавление еды
- Свободный текст: «гречка 200, грудка гриль, сникерс». Распознавание локально по базе (названия + синонимы, стемминг, учёт частоты).
- Над распознанным словом — всплывающее меню как при выделении текста: иконка, название, мелко БЖУ; справа стрелка → выбор варианта. Тап — подтвердить; если вес не написан — выбор граммов или штук.
- Подтверждённый фрагмент стирается из текста, вместо него горизонтальная панель: иконка, название, граммы/штуки, ккал и БЖУ. Тап — модалка правки граммов и БЖУ только для этой записи.
- Штучные продукты по умолчанию в штуках (Сникерс 1 шт ≈ 50 г, Орео 1 шт ≈ 11 г).
- Ряд кнопок по возрастанию размера: сканер штрихкода (маленькая, только иконка «штрихкод в рамке») · «Добавить блюдо» (средняя) · «Создать блюдо» (самая крупная, с бейджем числа продуктов).
- Нераспознанное слово — только «Создать продукт» (шторка с барабанами БЖУ). Оценки от Claude здесь нет.
- «Недавние» + «Посмотреть все». Чип времени: день (сегодня/вчера/дата), время, приём пищи (по умолчанию по времени).

## База продуктов
- БЖУ на 100 г; у штучных — на 1 шт.
- Список: поиск по названию; тип Все / Продукты / Блюда; период (сегодня / неделя / месяц); теги с иконками в одну горизонтально прокручиваемую строку, включая «Штучные».
- Продукт: фото, название, штрихкод (поле + сканер), категории с подписями, «На 100 г / На 1 шт» (+ вес штуки), БЖУ вертикальными барабанами, ккал считаются из БЖУ.

## Блюда
- Порция: ½ · ⅓ · ¼ (по умолчанию) · ⅙ · свой вес; КБЖУ на порцию.
- Состав — каждый ингредиент с точными граммами. Граммы — чип, по нажатию/зажатию раскрывается в вертикальный барабан, значение в бабле сбоку. Свайп влево по ингредиенту — удалить с отменой.
- Вес готового блюда — горизонтальная линейка-барабан. Ниже — рецепт или кнопка «Записать рецепт».
- Название, фото, штрихкод редактируются.
- При записи блюда в дневник можно поменять граммы ингредиентов **только для этой записи**, рецепт по умолчанию не меняется.

## Цели, профиль, настройка
- Первая настройка: шаги с полосками прогресса по центру, без текста «шаг X из Y»; пол, возраст/рост/вес барабанами (вес шагом 0,5 кг), цель, активность, итог норм. Итог: тап по карточке нормы → барабаны Б/Ж/У с шагом 1 г, «Отмена» / «Готово».
- Цели: белок на кг — горизонтальный барабан 1,6–2,2; Б/Ж/У нормы — чипы с барабанами по нажатию/зажатию, шаг 1 г.
- Тренировки: «Дни недели» / «Через N дней» (X дней тренировок, Y отдыха) / «Вахта» (активный период, перерыв, режим внутри), предпросмотр на 4 недели.
- Настройки: напоминание о весе — дни недели + время; недельный отчёт — день + время.

## Неделя (отчёт)
- Сверху сводка: баланс перебор/недобор за 6 дней, изменение веса со спарклайном, средние Б/Ж/У относительно нормы и чего не хватает.
- Ниже — горизонтальная лента вертикальных карточек дней, прошлые дни слева, сегодня справа и выделено (крупнее, розовый контейнер). В карточке — волнистое кольцо с калориями внутри.

## Ассистент (Claude) — версия 0.6+
- Только через свой сервер-посредник (ключ API не в приложении). В запрос — обезличенные сводки, не сырой дневник; явное согласие пользователя.
- Функции: недельный разбор, прогноз даты цели по адаптивному расходу (TDEE = ср. потребление − Δтренда×7700/дни), советы чем добрать БЖУ из частых продуктов.

## Релиз в Google Play (позже)
- Отдельный вариант сборки без самообновления и без REQUEST_INSTALL_PACKAGES.
- Настроить `allowBackup`/правила бэкапа (данные о здоровье), политика конфиденциальности, Data Safety.
- Подписка только на ассистента, трекер бесплатный.
